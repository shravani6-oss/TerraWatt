# GreenAI - 5-minute demo script
1. **(30 s) Motivation** - Home page. "Renewable adoption differs hugely across countries. GreenAI predicts, classifies and groups countries using 21 years of data from 176 countries."
2. **(45 s) Data** - Dataset Explorer. Show first/last rows, then the missing-value heatmap. "Two columns had more than 50% missing values and were dropped; the rest are imputed inside pipelines so test data never leaks."
3. **(45 s) EDA** - EDA Dashboard. Drag the year slider, pick India/China/Brazil, show Trends and Electricity-access-vs-renewable. "Low-access countries often have a high renewable share - that is mostly traditional biomass."
4. **(45 s) Regression** - Model Comparison. "Chronological split: train on early years, test on later years. The baseline R2 is about 0; both linear models beat it." Then Energy Prediction: enter electricity access, clean-cooking access, GDP, click Predict.
5. **(45 s) Classification** - Sustainability Classification. Pick a country-year, classify, compare with actual. "High means above the training median share. The split is by country to avoid leakage."
6. **(45 s) Clustering** - Country Clustering. Show profiles, PCA plot, the priority list. "Labels come from measured profiles; GMM adds soft probabilities."
7. **(45 s) Validation** - Model Evaluation. Show grouped vs plain CV. "Plain CV looks much better because a country's rows leak between folds - the honest score is lower."
8. **(20 s) Honesty & close** - About page limitations; mention REPORT.md and that every number is generated by `train.py`.

**Commands to have ready:** `python train.py` (about 2-3 min, run it BEFORE the demo) and `streamlit run app.py`.
